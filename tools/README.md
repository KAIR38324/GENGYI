# 参考计算工具

`reference_calculations.py` 只承担可复算的模数、人数、储格、实体柜数与条件面积估算，不生成CAD、不建立人体运动模型，也没有实现完整卫生拓扑求解。

## 估算模板的限制

`template_estimate` 指定一个便于单元测试的数学连接族：横排深600，外置四分之一实心扇形R600，竖柜位于横排端头外；角件与直柜内域不重叠，竖柜长度恰为该模板的净排距。原参数表只给四分之一圆弧R600，并未证明实际角件是此实心扇形，故这个模板不是对原CAD的精确重建。

所有返回值都保留 `is_feasible_layout=false` 和未完成验证项。113.42㎡/134.20㎡是上述假设下的柜阵外包矩形预估，不是整个换鞋间含茶水柜、门口、设备及实际操作后的已验证最小面积。

实际插件应接入真实块的物理占地、连接端口与操作面，完成明确的卫生分隔验证后再给出有效容量。不要把这个参考脚本直接包装成“自动排布已经完成”。

## 插件开发命令

`python tools/dev.py check` 执行 Python 参考与 C# 核心回归；`build` 编译 AutoCAD2024 插件，`package` 生成含运行时与许可的完整包。核心与宿主验收分别报告，见 `docs/environment-report.md`。
