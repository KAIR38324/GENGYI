# GENGYI｜CAD 更衣设施一键布置插件开发交接

首版完整支持 **换鞋间、一更、二更三种房间模式**，可在男女子房间间切换。依据原方案分别布置 S 形双面鞋柜、12门个人衣柜和工装衣架，支持人数估算、实际边界内多方案、默认正交拖动及各房间独立实时统计。

**当前已实现三模式 C# 核心和 AutoCAD 2024 插件工程（v0.5.2）**：房间切换、人数参数、不规则边界/障碍选择、多候选、临时预览、正交拖动、原生块入图、原块绑定/导入、统计与图纸内持久化均有源码实现。核心回归与编译已验证；Windows CAD 加载、原生编辑/撤销和原块图面验收仍需真实宿主执行，尚不能称已完成现场验收。

目标为用户指定的 **CAD 2024**，按 AutoCAD 2024 Windows x64 / .NET Framework 4.8 构建。运行 `python tools/dev.py check` 检查，运行 `python tools/dev.py package` 生成 `artifacts/Gengyi.AutoCAD2024.zip`。在目标 CAD 中 `NETLOAD` 加载包内主 DLL，执行 `GYSETUP` 打开三模式面板。

**v0.5.2 基本操作：选单班或双班、输入每班人数 → 设置是否允许叠放 → 预览面积、设备与尺寸 → 选择房间边界 → 设置出入口和通行区 → 生成、调整、确认入图。** 叠放选择直接放在人数之后，预览不替用户确定房间。支持闭合凹形、斜边和弧边多段线，实际面积与外包长宽分开；缺角和障碍不得放柜。一更柜背可贴墙，柜间通道净空至少1100mm，按两侧柜面间距计算；背靠背和同排贴靠不套该通道规则。S48仍须24—48—24夹住，允许连续24或全24。鞋柜宽650mm（中央50mm风道），转角R650；图面用最多两行显示型号、人数和必要层数，缺图块时在确认步骤提供绑定或明确图片重建入口。

持久安装：退出 CAD，将完整 `Gengyi.bundle` 放进 `%APPDATA%\Autodesk\ApplicationPlugins\`，重启 CAD。插件配置为每次 CAD 启动时加载；打开图纸后用 `GYSETUP` 显示面板。

使用流程见 [用户指南](docs/09_USER_GUIDE.md)，开发与加载见 [开发说明](docs/08_DEVELOPMENT.md)，真实验证范围见 [实测报告](docs/environment-report.md)。原方案 10 张图片保持原字节；仓库仍没有用户原生 DWG/DXF 块库。可在本地绑定/导入原块，或明确启用 `image_reconstructed` 重建模式，不将示意块冒充原 CAD 块。

## 已明确的容量与尺寸

| 组件 | 每侧列数 × 每柜层数 | 上下柜数量 | 两侧合计储格 | 人数 | 外形 L×D×H（mm） |
|---|---:|---:|---:|---:|---|
| S12 | 4×3 | 1 | 24 | 12 | 1000×650×600，长度为推算的定制模数 |
| S18 | 6×3 | 1 | 36 | 18 | 1500×650×600，长度为推算的定制模数 |
| S24 | 8×3 | 1 | 48 | 24 | 2000×650×600，用户与原参数共同确认 |
| S48 | 8×3 | 2 | 96 | 48 | 2000×650×1200，直接叠放的名义高度 |

每人占脏、净两格。**S24 两面合计 48 格只服务 24 人。** 单格名义分配空间为 `250×300×200 mm`；这是模数分配，不能作为内净尺寸或门板加工尺寸。原参数图的 `260×168 mm` 门尺寸与 250 mm 列距冲突，已列为待核项。

横排和竖向连接均可由鞋柜组成；连接柜本身在两侧可达、格口可用时计容。R650 四分之一弧形角件独立列项，默认不计储鞋容量。双层柜按 48 人存储计，但不能自动把 1200 mm 顶面当作原有 600 mm 跨坐座面。

## 核心设计要求

- 换鞋间只生成完整 S 形柜链，至少三排，以连接柜和交替的 R650 圆弧转角相接。放不下时提示调整边界、门位或净距。
- 其他边界柜距选定实际边界 **1000 mm**；本仓库将其作为默认最小净距和优先贴合目标，不擅自套用于所有柜间净距。
- 脏净两侧不能绕端直通，转换应通过已定义的跨柜位置。仅看起来像 S 形不算验证通过。
- 四周留 1000 mm 的孤立 S 形柜阵可能绕行。必须结合真实端部封闭/固定边界与脏侧、净侧出入口检查；缺少信息时标“卫生分隔待核”，不能自动通过，也不擅加应急走道。
- 换鞋间和一更按单班或双班合计，二更按一班周转。分房后各自乘 **1.1** 向上取整。出入口逐门校核，通行保留区可供人员通行。
- 不加淋浴，不添加妇卫等候、妇卫处理、洗衣附属间等用户未要求的功能。
- 输出真实块参照、清晰分层、模型空间标注；无多余填充、无额外纸空间出图布局。

## 运行参考计算

```bash
python tools/reference_calculations.py --people 600 --reserve 0
python -m unittest discover -s tests -v
```

历史参考计算器给出模块、柜数、名义储量及带条件的 S 形柜阵包络估算；**不声称已生成可用 CAD 排布，也不把柜体投影面积当房间面积**。真正的候选必须通过图块、门扇、两侧操作、卫生分隔和边界检查。
