## 3. 轻量实现边界

- 一个 C#/.NET Framework 4.8 插件工程，内部按计算、CAD操作、界面分目录；独立计算不引用 CAD GUI。必要测试可以链接同一份核心代码，不需要拆出服务或一组通用框架。
- 使用宿主常规控件构成按需弹窗；不嵌入网页编辑器，不搭账号、服务器、云数据库或管理平台。云端是开发位置，不是插件运行时的在线依赖。
- 弹窗常显目标、有效容量、缺口、已放数量、问题数；详细统计折叠，问题可定位图中实例。
- 入口、命令、块、图层、数据字典和资源采用 `GENGYI` 命名空间/前缀；不覆盖已有资源、不替换天正命令、不写天正CUI或快捷键、不修改 CAD 全局设置。点选与拖动应正确处理焦点，完成/取消后恢复上下文。
- 正式输出原生 `BlockReference`；候选与拖动用临时图形。确认一次可一次撤销；取消不残留实体。模型空间表达，不额外生成纸空间图框或多余填充。
- 拖动中轻量更新吸附、距离、冲突与人数反馈；落位及确认前精确复核。原生命令触发标脏/去抖，在安全上下文重新读取，不在每个数据库回调中递归改图。
- 图片块先实现，保留清晰的本地替换/导入接入口；将来取得原块也不要求上传公司DWG。

## 4. 必须保留的业务规则

- 当前600在册、300当班、男女1:1、备用默认0%；鞋柜和一更按在册，二更按当班；男女取整守恒、备用在分房后计算。人数可改，不能写死600。
- S12/S18/S24/S48分别12/18/24/48人；S24为48实物格，S48为96格、两个实体箱体、一个地面占位。连接柜是真柜，圆弧角件默认0容量。
- S型需真实横竖柜、圆弧及连接关系；不能以孤立平行排代替。鞋柜1000mm边界规则不自动套给一更/二更。
- 仅几何可放不能证明卫生隔离。需检查实体封闭、防绕端、脏净种子、跨柜转换与两侧操作可达；叠柜储存和跨柜能力分别判断。
- 一更1140×500×2095、三列四层12门；二更挂位按逐段端距、实际挂点及去重计数，不凭两面视觉翻倍。450是结构横管长度，650是吊杆构件长度，不是安装标高。
- 名义容量、有效容量、未核容量、不可用容量和人数缺口分别保留；无员工绑定时不用“已分配人数”代替有效人位。
- 几何、卫生、操作条件和图块样式分别给状态。未核尺寸不得以默认数字冒称工程实测；原图R600半径口径、260门宽与250列距冲突、挂架端距和人体活动尺寸仍需核对。
- 不加淋浴、无关房间或用户已取消的连续应急通路。

详细原始依据仍见 docs/00–07 和 data；以上是轻量化补充，不是删掉原有容量、几何与三模式要求。

## 5. 云端开发顺序

1. 运行原有Python参考测试与计算，检查10张原始图片；提交环境说明，不假设云端有AutoCAD。
2. 制作一张可核对的二维设备汇总样张，包含来源、关键尺寸、推算项、冲突项和待确认项；同等尺度参考图片。样张是核对材料，不替代宿主验收。用户确认前可继续独立算法、数据和导入流程，但不能把未确认模板标成已认可。
3. 按现有规则实现三模式核心、少量候选、几何及容量校核，建立必要的反例测试；不先堆通用求解框架。
4. 完成一个按需弹窗、图面约束输入、临时预览、原生块落图、手调、统计、图纸持久化和撤销。分别跑通三模式、五房间。
5. 云端提供源码、构建/打包脚本、可用时的net48编译产物，以及本地安装和验收说明。编译必须使用合法取得的对应AutoCAD引用；不把本机Autodesk DLL、许可文件或公司DWG上传GitHub。引用若未在云端配置，应清楚报告该编译项待执行，继续可执行的独立开发与测试。
6. 由用户本地执行AutoCAD2024+天正的加载、焦点/点选、拖动、原生命令统计、取消/撤销、保存重开、单位/UCS及样式核对。提供可重复的测试步骤或安全测试图，不把云端测试写成宿主实测。
