## 实际执行环境与依赖

Debian GNU/Linux 13 x86_64、Python 3.12.14、仓库内 .NET SDK 10.0.404。SDK下载核过微软发布元数据 SHA512；SDK只用于编译，插件运行时仍是 Framework4.8。AutoCAD.NET/Core/Model24.3.0、Framework ReferenceAssemblies1.0.3、NetTopologySuite2.6.0、Newtonsoft.Json13.0.4及其必要运行时均由锁文件固定。

本环境没有 Windows AutoCAD 可执行宿主，也没有用户原生设备块库。没有安装非授权 CAD、改安全加载策略或上传公司图纸。原块快照只在用户本机暂存求哈希并删除，不进入公开源码。

## v0.3.0 启动加载配置

根据用户要求，将包的 LoadOnAutoCADStartup 显式设为 True，保留按命令加载后备，并关闭安装时的即时加载。包内版本、主DLL及核心版本统一为0.3.0。核对了31个命令、模块路径、ZIP结构及构建元数据；启动加载不自动打开面板，不改变安全信任策略。真实CAD每次启动加载仍待宿主验收。

## v0.3.0 基础流程修复

将停靠面板改为布置、设备与图块、高级参数三页，主流程按人数、面积/长宽、定框与方案确认展开。人数和参数变化后即时刷新面积建议；开始操作和切房间前自动保存输入，空闲同步保留当前未保存输入。候选摘要显示单柜/双柜、箱体和容量；缺块时就在确认步骤给出原块绑定或明确图片重建入口。

三模式均可在无边界时枚举真实设备尺寸的矩形预排，鞋柜与精排共享R600柜链构造。提供不同长宽及明确的叠柜方案，面积按矩形包络计算，设备投影单列。CAD Suggested 定框以临时矩形/设备轮廓/尺寸面积随光标预览，支持90度旋转；取消不提交边界或图元。预排范围不等于最小面积，门柱、辅助设备、衣物、封闭及实际操作仍需后续核查。

预览、拖动和原生块内附加属性统一显示型号、人数、每侧层数、格数与高度。S48明确上下2柜/每侧6层，衣柜明确3列4层，挂架按实际挂点计数。GYSETUP会给已有受管理实例补齐标签，不修改原CAD块定义；ATTSYNC可能清除这些自有属性，再执行GYSETUP恢复。

新增21项核心检查覆盖三模式无边界估算、确定顺序、真实投影/不重叠/包络、600人113.42㎡参考模板、允许型号/禁叠放、短挂架逐段端距、分房备用、零人数和标识口径，并验证同长挂架必须匹配实际挂点后才能绑定。实际Windows CAD的界面显示、关键词定框、标签图面及一次撤销尚未在本环境执行，不能以编译结果替代。
