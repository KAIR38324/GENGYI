# GENGYI v0.4.0 使用与宿主验收

本包面向 Windows AutoCAD 2024（R24.3 / .NET Framework 4.8 / x64）。当前是已经实现并通过核心测试、API 编译的插件版本，尚未在实际 CAD 中完成加载和操作验收。安装包保留 `Contents/Windows` 内全部 DLL；不要将 Autodesk DLL 拷贝进来。

## 先按这条流程使用

执行 `GYSETUP` 打开工作台，标题显示 v0.4.0；`GYENV` 可查看实际 DLL 路径。按「布置」页顺序：

1. 选房间，输入在册、当班人数、男女比例和备用率。
2. 换鞋间直接选择「不叠放」或「允许叠放」。允许时仍要求每个48人柜的两端相接24人单柜；可以连续24，也可以全24。一更、二更按各自设备规则计算。
3. 比较面积、长宽和设备示意，点击「在 CAD 中预览设备与尺寸」。在画布上移动参考图形，输入 `Rotate` 可旋转90度，单击确认预览；Esc取消。此时没有选定房间边界，也没有把设备或参考框写成图元。修改人数、叠放或参考方案后要重新预览。
4. 点击「选择我的房间边界（不规则 / 矩形）」，点选自己画的闭合多段线。支持凹形、斜边及弧边，显示实际面积和独立外包尺寸；参考矩形只是另一可选方式。
5. 补选真实门口、柱、障碍和固定封闭物，再指定入口；换鞋间分别选脏侧入口与净侧出口。点击「生成布置方案」，按实际轮廓比较、拖动和调整，凹口之外不能放柜。
6. 若缺图块，在同一步绑定原 CAD 设备块，或明确选择图片重建（待比对）；检查后确认入图。编辑与块库在独立页签，高级尺寸和核对参数另列。

面积建议是所列设备预排的矩形包络，设备投影单独显示。它还需结合门柱、辅助设备、衣物、真实封闭和操作条件校核，不是已证明的最小合格面积。换鞋单柜标「每侧3层」，S48标「上下2柜 / 每侧6层 / 高1200mm」，一更柜标「3列×4层」。旧版本已入图的受管理设备在执行 `GYSETUP` 时补上标识。原生 `ATTSYNC` 如清除了这些自有属性，再执行 `GYSETUP` 恢复。

## 持久安装与每次启动加载

关闭 CAD，将整个 `Gengyi.bundle` 文件夹放入 `%APPDATA%\Autodesk\ApplicationPlugins\`，没有该目录时新建。目录应为 `ApplicationPlugins\Gengyi.bundle\PackageContents.xml`，主 DLL 位于同一 bundle 下的 `Contents\Windows\`。不要把单个 DLL 放在 ApplicationPlugins 根目录。

v0.3.0 已显式设置 `LoadOnAutoCADStartup="True"`，保留按命令加载作为后备，关闭安装过程中的即时加载。完成安装后重启 CAD，加载器会尝试在启动时载入本插件；打开图纸后执行 `GYSETUP` 打开面板。启动加载不会自动弹出面板或修改图纸。自动发现和实际启动加载仍需在目标 CAD 内验收。

`NETLOAD` 是当前进程内的手动验证方式，不是持久安装步骤。安全提示中的“始终加载”用于记录对文件/发布者的信任，与启动加载配置分别处理。遵守 CAD 正常安全加载提示和可信位置设置，不关闭 SECURELOAD。

如果习惯 APPLOAD 的“启动组”，.NET DLL 可通过一个调用 NETLOAD 的 LSP 引导文件接入；本 bundle 已提供自动加载配置，通常只需选择这一种安装方式。更新已安装版本前先退出 CAD，再替换完整 bundle，保留个人图纸与本地块库。

官方依据：[AutoCAD 2024 加载参数](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-Customization/files/GUID-3C25E517-8660-4BB7-9447-2310462EF06F.htm)、[Autodesk：自动加载 DLL](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-autoload-DLLs-with-AutoCAD.html)。

## 边界、障碍与已有图纸

边界须为一条有效闭合多段线，不支持把四条散线或开口线直接当房间；自交、零面积、非共面或过度复杂轮廓会明确拒绝，单个轮廓最多20000个采样点。弧段采用不超过0.05mm的弦误差，房间布置轮廓再作保守内缩；实际面积仍来自原多段线，鞋柜1000mm净距按实际规划轮廓校核。曲线障碍按已知误差保守外扩用于碰撞，曲线边界/封闭物的脏净隔离通过结论不会直接认证为精确合格。

柱、孔洞、门扇和门口保留区通过「门口 / 障碍」提供，实际隔板/固定阻隔用「实际封闭物」，不能拿不存在的障碍冒充隔断。边界只确定外轮廓；未知门位、安装和更衣动作仍需输入或核对。

已有设备时仍可重选共面的真实边界。设备、实际障碍、封闭物和入口种子保持世界位置，旧候选清空后重新校核。原生修改同一边界会重读完整轮廓，即使外包长宽不变也能识别凹口变化；删除、开口或自交会使校核失效。

旧矩形项目可由新版读取。保存新状态使用项目格式2.0，旧插件会拒绝读取，避免错误忽略不规则轮廓；继续编辑请使用v0.4.0或后续兼容版本。安装包中完整 `Gengyi.bundle` 文件夹名称保持一致。

## 三种模式

| 模式 | 设备和人数口径 | 自动候选与特有校核 |
| --- | --- | --- |
| 换鞋 | 在册人数；S24=24 人/48格，S48=48人/96格/2箱体 | 连续 S 柜链、12/18/24 混合、可选局部叠放、横竖方向；R600 圆弧、连接柜、1000 边界、脏净分隔及跨柜流程 |
| 一更 | 按性别在册人数；12门柜 1140×500×2095 | 沿墙、多列、背靠背；实际柜门/取物/更衣操作空间及入口可达；不套鞋柜边距 |
| 二更 | 按性别当班人数；按独立实际挂点计位 | 沿墙分段、中岛多段、横竖方向；每段单独端距、挂点去重、安装标高与支撑/衣物操作条件 |

600/300、男女1:1、0备用时：鞋位目标600；男女一更各300人、各25个12门柜；男女二更各150挂位。柜体投影不是房间面积。600在册不表示600人同时操作。

S48 允许存储，但 1200 mm 顶面不作为 600 mm 跨坐面。单层跨柜点可通过“跨柜点开关”指定；移走连接柜或端部封闭物后重新校核。软件分别检查实体封闭和配置人员宽度下的可绕行性，小缝过不去也不会被标成已真实封闭。

二更挂钩默认节距100、端距50/50，端距是显式假设。现有挂架保存实际挂点集合；仅改变规划节距不改变已入图挂点。改长度会按当前明确的挂钩参数提出新挂点，并要求对应长度/挂点的块；不会拉伸一个原块来冒充新的挂架。650是吊杆构件长度，不是安装离地标高。

## 原块与重建

“选取原块”（GYBLOCK）：选择当前图中的原始块实例，标定物理原点和长度方向，再点实际深度另一侧。尺寸不一致会明确拒绝，不能用缩放将 S24 冒充 S12。物理占地可选独立闭合轮廓，不使用含文字和尺寸线的整体 Extents。动态属性、属性文字和嵌套定义保留，绑定版本保存于当前图纸。

“导入DWG/DXF”（GYIMPORT）：只读取用户选定文件，列出块名，导入所选块及依赖作为标定样本。样本不计人数；随后用 GYBLOCK 绑定。重名定义采用隔离命名，原有块不被替换。包含未处理外参或代理对象时给出具体问题。公司图纸和块库不会上传。

“据图重建”（GYREBUILD）：为所选候选补充 `image_reconstructed` 块，已绑定的原 CAD 块优先保留，实际圆弧保留为圆弧。S12/18 按列数重建，不挤压 S24；S48 一组占地、两实体箱体，并有叠放标记。缺尺寸的镜子、紫外线设备等不虚构外形，需原块/真实占地接入。重建块只是据图建模的待比对版本，不能称已复用原 CAD 块。

“原块比对确认”（GYVERIFY）：只有在真实 CAD 中完成同尺度比较后，记录用户确认。应核对外轮廓、格线/列距、圆角、朝向、颜色线型、物理尺寸及实际挂点。该确认不会把重建来源改成 `original_cad`。来源确认与门扇/更衣动作、安装和卫生分隔分别保存。

辅助设备通过“添加辅助设备”接入。茶杯柜、镜子、紫外线设备等不增加鞋位、个人柜门位或挂位；缺外形/块时明确提示，不自动删除或虚构设备。

## 统计与编辑

面板区分目标、名义、几何可用、已验证有效、受阻、待核和条件缺口。有效容量未核时显示“待核”，条件缺口基于几何可用量，不能当作已满足人数。班次使用吞吐、员工编号分配没有被名义容量替代。异常定位（GYLOCATE）支持实例ID/前缀、柜组ID或句柄；校核发现可正常步行绕端时，会尽可能以红色临时线显示经连续净空检查的路径。路径显示的采样超时/失败不会把拓扑失败改成通过。

原生 MOVE/COPY/ROTATE/ERASE、夹点和 UNDO/REDO 后，数据库事件只标记需更新，在命令结束后的空闲上下文重读。复制块根据真实句柄区分身份，复制的连接组先解除与原组的绑定并显示待核，避免拖动复制组连带原组。用“确认连接组”（GYGROUP）选择复制设备，确认新组或明确解除编组。删除不继续使用旧缓存；动态属性变更、非正交旋转、缩放、镜像或移离房间平面会明确失效，而不是继续计满。

“锁定/解锁”保护插件自己的编辑与方案替换。CAD 原生编辑仍由用户控制；发生原生变更会照实同步并重新校核。跨房间移动通过“转入本房间”明确归属；不会因为在图面上靠近另一个房间就重复认定容量。图中状态存于扩展字典，保存后重开可恢复；其真实宿主行为仍需以下验收。

## 真实 CAD 必须执行的验收

1. 分别在换鞋、男一更、女二更选边界、生成不同候选、预览拖动再取消。比对设备图元数，取消不应增加实体/图层；回来后候选保留。
2. 将实际原块绑定到各模式，比较同尺度图面。重建来源必须仍清楚可见；没有原块不能将该项判为通过。
3. 确认入图后一次 UNDO，应撤回整个当前房间生成和相关元数据，其他房间与原图实体保持；REDO 应恢复相同统计。
4. 原生 COPY 一个 S48，应增加1组、2箱体、48名义人位。MOVE/ERASE/ROTATE 和撤销重做后检查实时结果；非正交/缩放应失效。
5. 男一更删一柜只影响男一更12位；女二更删一段按实际挂点扣减。切换回来保留之前手工编辑。
6. 换鞋柜阵周边可绕行时必须不通过。补入真实封闭物，指定正确种子和低柜转换点，再检查隔离与流程；移走封闭物后失效。
7. 核对实际开门、更衣动作、人员宽度、挂架支撑/标高和衣物占用，填入参数并确认。不能只点确认框而没有现场依据。
8. 保存、关闭、重开同一 DWG，在另一台同版本 CAD 加载插件，核对房间状态、块来源、统计及原生操作同步。

核心测试、编译和包结构检查已可自动执行；以上宿主步骤没有在当前 Linux 环境运行，不预先勾选通过。

常用命令：`GYSETUP`、`GYENV`、`GYPLAN`、`GYESTIMATE`、`GYRECT`、`GYOBSTACLES`、`GYCLOSURES`、`GYSEEDS`、`GYGENERATE`、`GYPREVIEW`、`GYCOMMIT`、`GYCANCEL`、`GYDRAG`、`GYROTATE`、`GYTYPE`、`GYLENGTH`、`GYCROSS`、`GYBLOCK`、`GYIMPORT`、`GYREBUILD`、`GYVERIFY`、`GYADD`、`GYLOCK`、`GYDELETE`、`GYTRANSFER`、`GYCHECK`、`GYSTATS`、`GYEXPORT`。导出是本地 JSON，并保留毫米坐标、来源和独立校核状态。

## 48人柜必须交错布置

每个S48两端各须有一个实际相接的S24单柜，形成24—48—24；允许连续重复24—48—24—48—24，禁止全S48、相邻S48及柜链端部S48。S12/S18、转角或隔空低柜不能代替这两个S24。接触容差0.1mm仅用于计算，不表示制造安装已核。

人数面积预估与正式候选统一按这条规则计算，不会再按任意叠放低估占地。换型号、单柜拖动/旋转、删除、添加和跨房转移不得新增违规；要调整含S48柜段，可成组移动，或先把相关S48改回S24。旧违规图纸可以逐柜修复，软件不自动搬动或删除原柜。CAD原生编辑后重新校核，违规S48只保留名义数量、不计几何可用，入图按钮和底部状态会显示未通过。

## 当前柜宽、通风道与简短标注

鞋柜总深650mm，其中中央50mm通风道，两侧名义各300mm；转角R650。一更衣柜1140×500×2095mm、12人/柜。图上仅保留如「S24 24人 / 单柜3层」「S48 48人 / 双柜6层」「衣柜12人 / 4层」，转角只标R650，格数/总高等不再逐块堆叠。原有标识在GYSETUP时更新自有文字属性，不修改源定义。

旧600宽、R600原块保持原尺寸显示，但不再作为新650布局的有效源；请重新绑定实尺寸原块或明确按新参数重建。不通过缩放、改字或旧块名复用冒充新设备。
