# 插件验收场景与反例

更新：2026-11-17。下列为本地开发的验收要求；除仓库另有对应实测记录者外，均为待实现、待执行。不能把测试清单的存在当作测试通过。

## 1. 证据与通过口径

每项保存输入配置、选定设备库版本、宿主品牌/版本/补丁、期望结果、实际结果和必要截图或输出图纸。纯算法测试可脱离 CAD 执行；原块外观、选择矩形、拖动、撤销及原生命令必须在真实宿主内验证。失败必须能定位到实例或条件，不能只有一个红色“失败”。

以下条件不能相互替代：容量算术正确、柜体能塞进矩形、两侧可取放、只能跨柜换侧、原图块样式一致、人体操作条件、最终图纸可打开。分别给出结论。

## 2. 容量与柜型

| 编号 | 输入/操作 | 必须出现的结果 |
| --- | --- | --- |
| C01 | 24 人柜；每侧 8 列 × 3 层 | 人位 24；总格数 48；同一人的两格分处脏净两侧，不算成 48 人 |
| C02 | 2000 × 600 × 600 外包按理想均分 | 名义格节距 250 × 300 × 200 mm；明确不是扣除板厚后的净空 |
| C03 | 参数表门片宽 260 mm 与 250 mm 名义列节距同时存在 | 显示参数冲突/待核；不能把 260 强塞进 250 或隐式改成 8 列以外 |
| C04 | 12、18、24 人定制柜 | 名义长度分别 1000、1500、2000 mm；每侧列数 4、6、8；同样 3 层；来源标记为尺寸推导，实际定制外框另核 |
| C05 | 24 人柜上下叠两只 | 名义 48 人、96 格、1 个地面组、2 个物理模块；柜投影仍 1.2 m²；不重复绘制或重复统计 |
| C06 | 输入 600、备用率 0、只准 24 人柜 | 理论 25 组、600 人、48 格/组；独立柜体投影和为 30 m²；不能把 30 m² 标成换鞋房面积 |
| C07 | 输入 601、备用率 0、只准 24 人柜 | 理论 26 组、624 人；余量 23；禁止向下取整 |
| C08 | 输入 600、备用率 10%、只准 24 人柜 | 明示目标 660；理论 28 组、672 人、余量 12；不得仍显示目标 600 |
| C09 | 输入 600、备用率 10%、允许 12/24 混合 | 至少识别 27 × 24 + 1 × 12 = 660；仍需另做几何及操作校核 |
| C10 | 一只柜一面被墙/另一柜完全封死 | 名义容量仍显示，无法形成双侧完整配对的人位不得计入有效容量 |
| C11 | 连接柜转为纵向后某列操作面受遮挡 | 按列/配对位扣除受影响容量，不以“它是连接柜”整柜计满或整柜计零 |
| C12 | 只布置 1200 mm 高叠柜，没有定义可用跨柜转换点 | 容量与转换路径分开反馈；不能自动获得与低柜相同的跨坐操作数量 |
| C13 | 0、负数、小数人数、异常巨大数值 | 0 可用于空布局；负数及非整数给具体输入错误；超上限给明示原因且可取消，不冻结 CAD |

## 3. S 形连接、边界与脏净拓扑

| 编号 | 输入/操作 | 必须出现的结果 |
| --- | --- | --- |
| G01 | 横向柜与竖向柜端部连接 | 显示各自真实外形，净距由端口及端接方式计算；不能直接把连接柜长度当净距 |
| G02 | 两柜角部重叠 100 × 100 mm | 碰撞失败；不能重复计算重叠处柜位，面积用并集不会掩盖实体碰撞 |
| G03 | 两柜恰好端面贴合、无实体重叠 | 允许合法接合；连接图形成一条边；几何容差不得导致反复闪烁 |
| G04 | 拖开连接柜形成 10 mm 裂缝 | 几何连接标为断开；不能单靠人宽膨胀后过不去就宣称结构连续封闭 |
| G05 | 边界柜最近实体轮廓距边界 999 mm，公差按配置另列 | 边界距不足；不能用插入点或设备中心代替外轮廓测距 |
| G06 | 边界柜距离 1000 mm | 按边界规则通过；继续执行拓扑检查，而非整个候选直接通过 |
| G07 | S 形柜阵四周都留 1000 mm，周边可绕成一圈 | 脏净种子连通；明确指出绕行路径；不满足“只能跨柜” |
| G08 | 柜端与经过确认的固定阻隔共同构成连续隔离，入口分别在两侧 | 不跨柜的自由空间中脏净种子不连通；添加指定跨柜连接边后，两侧人员路径按预期连接 |
| G09 | G08 中移走一个端部阻隔或连接柜 | 立即发现绕行/断开；原“合格”状态不得留在缓存 |
| G10 | 出入口种子落入柜体、墙体或错误侧 | 报种子位置错误，不能将无路径误报为成功隔离 |
| G11 | 两侧均不连通且所有入口也到不了柜前 | 隔离检查可以成立，但可用性失败；不可把封死人员当最佳方案 |
| G12 | 精细缝隙、弯角、圆弧柜端、柱边窄通路 | 用实际轮廓和明确精度验证；必要时解析几何/局部加密，不能依赖粗网格漏检 |
| G13 | 同一布局旋转 90°、改变 UCS | 容量、实际距离和连通关系保持；脏净方向按变换正确更新 |
| G14 | 600 人目标在过小矩形内 | 显示实际最大有效人位、缺口及主要限制；不越界、不缩柜、不减边界距、不自动加叠柜冒充满足 |
| G15 | 整个 S 形段成组拖动 | 柜间端口相对关系保持；与边界/其他组关系重新检查 |

这部分检验的是正常使用中的脏净分隔。用户已要求保留跨柜方式，本插件不得为完成此表而擅自新增连续步行应急通路。它也不能仅凭这组局部测试给整层消防疏散作通过结论。

## 4. 原块外观和 CAD 完整性

| 编号 | 输入/操作 | 必须出现的结果 |
| --- | --- | --- |
| B01 | 导入用户原 DWG/DXF 的 24 人柜 | 图形、基点、外形尺寸和两侧方向可核对；以原生 INSERT/块参照落图，不是散线矩形冒名 |
| B02 | 只有截图，程序据图重建 | 记录 `image_reconstructed`；不得显示“已复用原 CAD 块”；按原图逐项比对后方可升级样式核对状态 |
| B03 | 使用历史 F-R3 自画符号 | 识别为 `legacy_generated`，不进入默认生产设备库 |
| B04 | 24 人派生 12 人柜 | 保持单列节距，减少列数；不能整体非等比压缩使格宽变 125 mm |
| B05 | 实际柜体外形与配置 2000 × 600 不一致 | 记录实测和配置差异，等待对应参数选择；不能后台缩放掩盖冲突 |
| B06 | 源图单位 mm、m、inch、未设单位四组 | 前三者换算后同一实物尺寸；未知单位要求校准；落图不出现 1000 倍或 25.4 倍错误 |
| B07 | 同名不同内容块已经存在于目标图 | 两者不被错误覆盖，哈希/映射可追溯；同名同内容可以复用 |
| B08 | 嵌套、动态、属性块；动态块名变为匿名名 | 依赖完整，状态正确；容量由绑定数据获取，不按匿名名称猜测 |
| B09 | 0°/90°/180°/270° 插入；可选镜像 | 图形、操作面、脏净标签及连接端口一同变换；镜像未启用时禁止静默镜像 |
| B10 | 原块含文字、引线或尺寸超出柜体 | 碰撞按独立柜体轮廓计算；注释不人为扩大柜体占地；图面仍做文字遮挡检查 |
| B11 | 将原图及插件输出并排，以相同尺度观察 | 格线、转角、柜端、内部图形、文字方向和层次逐项一致或有明确派生依据；保存比对证据 |
| B12 | 保存 DWG/DXF、关闭、重新打开，另一台同版本 CAD 打开 | 柜块、元数据、图层、字体映射和统计可恢复；没有仅在本机缓存才能显示的图块 |

## 5. 自动生成、编辑与统计

| 编号 | 输入/操作 | 必须出现的结果 |
| --- | --- | --- |
| U01 | 输入人数后尚未框选矩形 | 给出预估及假设；可以看到柜投影下界；不声称已保证某个房间面积可用 |
| U02 | 框选一个可行矩形 | 出现有真实构型差异的候选；每个候选的容量、柜型组合、面积和校核状态一一对应 |
| U03 | 求解得到多个纯平移或等效候选 | 去重；不能以大量近似重复图冒充多方案 |
| U04 | 仅有一个/零个有效解 | 如实显示，不复制候选凑到 3 个；不在后台放宽边界规则 |
| U05 | 鼠标拖动一只柜，按 R 旋转（或等效宿主操作） | 默认正交到局部轴；实时显示容量影响、距离和连接；键位有明确提示 |
| U06 | 悬停未落图、按 Esc 取消 | 已布置数、有效人位、数据库实体数恢复到动作前；无残留临时对象 |
| U07 | 有效布局中删除一只 24 人柜 | 名义人位立即减少 24；有效人位还应计入可能出现的额外拓扑或可达损失；不能只做固定减法 |
| U08 | 原生 MOVE/COPY/ERASE、夹点、UNDO/REDO | 面板同步；复制实例新 ID；撤销后 ID/容量/连接一致；没有重复累计 |
| U09 | 复制一个双层组 | 地面组 +1、模块 +2、名义人位 +48；与通过性有关的有效人位重新计算 |
| U10 | 炸开受管理的柜块 | 提示该对象脱离管理，删除旧缓存计数；不将散线和原实例同时计算 |
| U11 | 一次接受整套方案，然后一次撤销 | 整套方案与对应统计回退，用户原有图元保持 |
| U12 | 生成时取消、切换/关闭图纸、异常抛出 | 取消任务、清理临时显示、释放文档锁；不把 A 图的结果写到 B 图 |
| U13 | 改目标人数，未改现有柜子 | 重新计算缺口/余量；不在用户未选自动重排时移动已布置柜子 |
| U14 | 混合 12/18/24/48，面板“还差多少柜” | 给出带柜型的补齐组合和对应人位；不能用统一 24 除法掩盖混合策略 |
| U15 | 导出统计再重新打开布局 | 目标、备用、实例数、物理模块数、名义/有效/已分配三种容量分别一致 |

## 6. 首版一更、二更及房间切换验收

- 一更 1140 × 500 × 2095 mm、12 门柜：尺寸及容量按原设备表；取放面和柜门动作独立于块外观。不能把 12 门误画成 12 列占地，也不能把门立面图直接当平面占地。
- 二更原架的横向圆管长 450 mm、竖向高度 650 mm（不含螺栓）、挂钩长 50 mm、直径 4 mm、间距 100 mm、主圆管直径 25 mm、壁厚 2 mm。架总长依图纸；450 mm 不等于整条挂架总长。
- 二更挂位由有效挂钩数量核算，明确端距、单/双面和可用段；不能不说明端部条件就固定用“总长 / 100”计算。取整、转角不可用段和障碍遮挡要有反例。
- 当前项目男女各 150 人当班、各 300 人在册；二更按当班周转。一更与鞋柜的储存需求不随二更清空而自动减为 300 人。

### 6.1 房间模式功能回归（首版必过）

1. 换鞋→男一更→女二更→返回换鞋，原边界、候选、设备、统计和修改状态完整保留。
2. 600在册/300当班/1:1/零备用：共用换鞋600；男女一更各300、各25个12门柜；男女二更各150挂位，不能串用600。
3. 男一更删一柜，名义容量减12且仅影响该房间；换鞋和女一更保持原值。
4. 二更拆分或拉短挂架后逐段按100节距与各段端距重新计算，末端及转角不重复计位。
5. 一更沿墙柜背靠墙不因鞋柜1000边界规则误报；仍检查其前侧柜门、更衣动作与真实走道。
6. 二更650是吊杆长度，不得直接把架子安装标高设为650；缺安装标高时保留待核字段。
7. 三种模式各能自动生成有实际差别的候选（不足时说明原因）、正交拖动、确认原块入图及一次撤销。
8. 当前房间统计与项目各房间汇总分开；跨房间移动设备重新归属，原房减、新房加，不能两边同时计数。
9. 同一模式存在两个不同房间实例时，不共享同一边界或覆盖另一实例；人员分配不得重复宣告满足。
10. 601在册按1:1拆成301/300，301当班拆成151/150；两个性别之和必须与输入一致，显示取整策略。

## 7. 性能与稳定性验收

性能数值属于初始目标，必须写明测试机器和实际测量。推荐至少记录：600 人典型矩形首个有效候选时间、全部候选时间、约 30–100 个柜组拖动的 P50/P95 响应、持续 100 次拖放和 20 次撤销重做后对象数量/内存变化，以及极小矩形无解时取消响应。架构文档提出的 100 ms、2 秒、10 秒不是已测指标。

后台线程不直接访问 CAD 对象；反复取消生成不得导致 CAD 崩溃或锁未释放。若求解超过设定时间，返回已找到的候选、搜索进度及“未完成穷举”，不能将超时等同于无解，也不能称最优。

## 8. 完成定义

只有换鞋、一更、二更三个模式均满足以下条件才可称“更衣设施一键布置首版可用”：真实目标宿主可加载；输入人数到框矩形、候选预览、原生块落图、正交拖动、实时计数、保存重开完整贯通；上述容量核心与拓扑反例通过；原块来源真实可追溯；发现不满足时能给出可定位原因；用户原图没有被覆盖或无关修改。

原始 CAD 块暂缺时，可以先交付算法、据图重建候选块和可运行预览，但必须分别标明状态。不得只完成一个网页示意器、截图或 JSON 计算，就宣称 CAD 插件已经交付。

## 48人柜交错硬规则

- 24—48—24 与24—48—24—48—24实际端面对接时通过邻接检查，旋转整组或原块方向反转不改变结果。
- 全48、相邻48、链端48、S12/S18代替两邻24、侧面擦碰和隔空邻柜必须失败并定位S48。
- 删除所需24、把邻24改48或单柜拖开会新增违规时，插件操作不得提交；旧违规图纸允许逐柜改回24进行修复。
- 面积估算和实际候选都满足同一约束，名义目标仍须达到；不足时如实报告，不能取消交错规则凑容量。原生CAD编辑及UNDO/REDO后的显示与阻止入图须在实际宿主核查。

## 不规则边界与先预览流程

1. 人数后直接选择不叠放/允许叠放，先GYPLAN预览，再选真实边界；取消规划预览不改变原边界/候选/已存签名。修改人数、叠放或参考编号后必须重预览，成功编号与GUI同步。
2. 凹L、U、斜边及弧边闭合多段线显示真实面积；缺角内不能放设备，即使它在外接矩形里。曲线标明误差，不把保守近似当精确隔离认证。
3. 换鞋、一更、二更在L形和含障碍区域均生成不同真实候选，完整足印不越界不缩放，鞋柜满足内凹/斜边1000mm净距；小空间如实显示缺量。
4. 原生移动凹口顶点但保持外包尺寸不变，重新校核须识别；保存重开和一次UNDO/REDO保留真实轮廓和坐标。
5. 新版可读旧矩形项目，未知格式拒绝；新多边形项目格式2.0防止旧插件把轮廓忽略。以上宿主交互项仍需真实CAD执行。

## 一更1100mm柜间净距

- 对向衣柜柜面净距1100mm通过，1099.9mm失败，涉及的两柜不可计为可用；调小预排/实际操作参数不能绕过。相同规则用于旋转后的柜面和真实不规则边界。
- 1100mm由两侧共用，不翻倍；500+1100+500的2100mm房间横断面允许两排柜。同排贴靠、背靠背贴靠不误报柜间通道。
- 面积预览、矩形及凹形实际生成均保证该下限。编辑新增违规需拒绝，追加时连同原有柜体检查；原生CAD编辑及撤销后的问题提示/定位须在宿主验证。
