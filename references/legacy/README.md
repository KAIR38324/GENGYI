本目录保留有用的失败证据，帮助本地开发避免重犯错误：

- `F_R3_design_REJECTED_FOR_SYMBOLS.json`：旧重建几何、房间与数量口径。其布局不是本轮插件固定模板；不能继承旧735/713/900等局部间距取代最新边界1000规则。

旧稿换鞋115.8417㎡、整体净558.4371㎡等是特定重建口径与未完全验证操作条件下的数字，不作为本插件的“最小面积证明”。原用户135㎡经验是对照工况，不是任意矩形/任意人数的合格阈值。

原图块源只能是用户本地原CAD或明确标识的原图重建；禁止拿历史生成稿换个名称冒充。
